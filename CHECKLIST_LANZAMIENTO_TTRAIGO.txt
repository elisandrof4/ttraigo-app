6. DGII/e-CF si emitirás comprobantes fiscales reales.

PASOS:
1. Esperar propagación de ttraigo.com.
2. Confirmar que www.ttraigo.com abre Ttraigo.
3. Subir launch-center.html a GitHub.
4. Revisar login, cliente, chofer, acompañante, admin, web, pagos, SOS y reportes.
5. Instalar Node.js y Android Studio para generar APK/AAB.
6. Ejecutar:
   npm install
   npm run cap:add:android
   npm run cap:sync
   npm run cap:open:android
7. En Android Studio:
   Build > Generate Signed Bundle / APK.
