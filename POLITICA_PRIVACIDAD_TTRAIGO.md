# POLÍTICA DE PRIVACIDAD — TTRAIGO

Ttraigo recopila datos necesarios para operar servicios de movilidad asistida, incluyendo nombre, teléfono, correo, ubicación GPS, documentos de verificación, historial de servicios, pagos y contactos de emergencia.

Usamos estos datos para solicitar servicios, asignar choferes y acompañantes, mostrar seguimiento GPS, proteger usuarios, procesar pagos y cumplir obligaciones legales.

No vendemos datos personales.

El usuario puede solicitar revisión, actualización o eliminación de datos escribiendo al soporte oficial de Ttraigo.

Última actualización: 2026.
